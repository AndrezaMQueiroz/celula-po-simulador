Experimento 1 · Como um LLM gera respostas

Qual é a próxima palavra?

O modelo não escolhe sempre a palavra mais provável. Ele sorteia, e a temperatura controla o quanto esse sorteio arrisca.

Eu me matriculei na PM3 para fazer um curso de ___
1.00

Baixa: previsível, repete a favorita. Alta: criativa, aparecem palavras raras.

Clique em "Gerar 20 vezes".
Para o PO: o mesmo prompt pode gerar respostas diferentes. Por isso testar uma vez só não prova que a feature funciona.

Exemplo didático. Os 5 primeiros valores vêm do slide do curso; os demais foram adicionados para ilustrar a cauda.

Experimento 2 · Medindo um modelo de classificação

“IA, este usuário é fraude?”

O modelo dá uma nota de risco de 0 a 1 para cada transação. Você decide a partir de que nota ele bloqueia. Mova o limiar e veja a troca entre fraude aprovada e cliente legítimo bloqueado.

0.50

Bloqueia quando a nota de risco ≥ limiar. Em 1.00 o modelo nunca bloqueia.

5%
