# Célula de PO · Simulador

Dois simuladores para a apresentação "IA para POs" (Módulo 1 do AI Product Specialist, PM3):

1. **Qual é a próxima palavra?** Mostra como a temperatura muda a escolha de palavras de um LLM.
2. **Matriz de confusão antifraude.** Limiar ajustável, com acurácia, precisão, recall e F1 calculados ao vivo.

Página estática, sem dependências. Os dados são fictícios.
